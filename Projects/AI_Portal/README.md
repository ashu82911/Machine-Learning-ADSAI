# 🇮🇳 FacebookIndia AI Portal

**Built by Ashu (ashu82911)**

India's AI-powered social portal for job search, networking & technical knowledge.

## 🚀 Live App
> Deploy on Streamlit Cloud with subdomain: `facebookindia-ai`
> URL: `https://facebookindia-ai.streamlit.app`

## Features
- 🏠 **Home** — Dashboard with activity stats
- 📰 **Feed** — Post, like, comment, share & stories (Facebook-like)
- 👤 **Profile** — Personal AI professional profile
- 🌐 **Network** — Connect, pending requests, people you may know
- 💼 **Job Search** — AI/ML/Cloud jobs with filters
- 🤖 **AshBot** — AI chatbot for tech & career Q&A
- 📚 **Knowledge Base** — ML, DL, DS, Cloud, Python learning
- 📊 **TATA Overview** — Editable Cloud Data Engineering overview
- 🔔 **Notifications** — Likes, comments, job alerts

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Cloud
1. Go to https://share.streamlit.io
2. Sign in with GitHub (ashu82911)
3. New app → repo: `ashu82911/Machine-Learning-ADSAI`
4. Branch: `ai-portal`
5. Main file: `Projects/AI_Portal/app.py`
6. **Advanced settings → App URL → set to: `facebookindia-ai`**
7. Click Deploy!
