# 🤖 AshTech AI Portal

**Built by Ashutosh Kumar Pandey**

An AI-powered company portal for job search and technical knowledge.

## Features
- 🏠 **Home** — Portal overview and feature highlights
- 💼 **Job Search** — Browse AI/ML/Data Science/Cloud jobs with filters
- 🤖 **AI Chatbot (AshBot)** — Ask anything about AI, ML, careers & tech
- 📚 **Knowledge Base** — Structured learning: ML, DL, DS, Cloud, Python
- 📊 **Ford Overview** — Editable executive overview (Cloud Data Engineering)

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Connect OpenAI (optional)
Add your OpenAI API key in the chatbot settings for smarter responses.
Without a key, AshBot uses a built-in rule-based knowledge engine.
